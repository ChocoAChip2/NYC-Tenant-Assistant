Off by default; guard runs in report mode first.
- `2026-09-20-hardening-sweep.txt` — An extensive verification pass (fuzzing, XSS audit, live-database checks, 253 browser assertions) and the four bugs it found: a user could lock themselves out of the entire app by typing a message starting with `enc:`; one undecryptable row took down every row beside it; retrieval could 500 a chat turn instead of degrading to an uncited answer; and the citation guard rejected six shapes of perfectly correct reply, including the closing period inside the quotation marks.
