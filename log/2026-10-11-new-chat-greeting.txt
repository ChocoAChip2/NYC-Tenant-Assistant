2026-10-11  A new chat opens with the greeting and a centred message box

Request (owner): a brand-new chat with no messages should open like a
new-chat page: the time-of-day greeting with the tenant's name, centred,
"How can I help you today?" under it, and the message box directly below,
until the first message is sent. Before, an empty conversation showed a
blank transcript with the composer docked at the bottom; the greeting only
appeared on /chat with no conversation.

Changed
- New partial templates/_greeting.html, used by both screens. Same
  greeting logic and ids: time of day, first name, email-handle fallback,
  server-rendered "Welcome, ..." before the script runs.
- No-conversation screen: the date, chips and "Continue with your
  building" are as they were. Only the subline changed, to "How can I help
  you today?".
- Empty conversation: .chat-area gets the class is-fresh, which centres
  the greeting and the composer. The single #chat-form stays in place;
  there is no second composer.
- When the first message renders, the class and the greeting are removed
  and the normal layout returns.

The brief and the code
- The brief said to leave _situation.html and the send gate as they were.
  Both were already removed on main by the "Your data" change merged
  earlier the same day (PR #59), so there was nothing to leave. The "Your
  data" button sits in the composer in the new layout too.
